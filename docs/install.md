# notte MF仕訳帳チェック インストール手順（Chrome）

MFクラウド会計の「仕訳帳」を開くと、誤りの可能性が高い仕訳に色と理由が出るようになります。
表示するだけで、MFのデータを書き換えることはありません。仕訳のデータがPCの外へ送られることもありません。

## 1. Tampermonkey を入れる（済んでいれば飛ばす）

1. Chrome ウェブストアで「Tampermonkey」を検索し、「Chrome に追加」
2. アドレス欄に `chrome://extensions` と入力して Enter
3. 画面の**いちばん上の帯の右端**にある「**デベロッパー モード**」をオンにする
4. Tampermonkey のカードの「詳細」を押し、「**ユーザー スクリプトを許可する**」をオンにする
5. Chrome をいったんすべて閉じて、開き直す

**3 と 4 は両方とも必要です。** 片方だけだと、スクリプトを保存するときに「ユーザー スクリプトが無効です」と出て動きません。

Chrome を開き直したあと、Tampermonkey の画面に「拡張機能の設定で『ユーザー スクリプトを許可する』を有効にしてください」と出ることがあります。そのときは 4 のスイッチがオフに戻っているので、もう一度オンにして、仕訳帳を再読み込みしてください。

## 2. スクリプトを入れる

1. 次の URL を Chrome で開く
   `https://raw.githubusercontent.com/notte-tax/notte-userscripts/main/dist/mf-journal-check.user.js`
2. Tampermonkey の画面が開くので「インストール」を押す
3. Tampermonkey のアイコン →「ダッシュボード」で、一覧に「notte MF仕訳帳チェック」があり、スイッチが緑になっていることを確かめる

以後、所内でルールを直すと自動で更新されます（Tampermonkey が定期的に確認します）。

## 3. 使い方

- MFクラウド会計の「会計帳簿」→「仕訳帳」を開く
- 気になる仕訳の左端に色の帯、右側に `R022` のような札が出ます。札にマウスを乗せると理由が出ます
  - 赤 = 修正必須 / オレンジ = 要確認 / 黄土色 = 懸念
- 画面右上のパネル
  - 件数のボタンを押すと、その重要度の次の行へ移動します
  - 「チェックする」を外すと一時的に止まります。「摘要の空欄も知らせる」で摘要空欄の指摘を出す・出さないを切り替えます
- 見ているのは「いま表示しているページ」だけです。重複候補（R051・R052）も表示中の仕訳どうしでしか比べません
- 「MFの画面が変わったため、チェックできません」と出たら、MF側の画面変更です。岩瀬に知らせてください

## 4. ルール番号の意味

| 札 | 内容 |
|---|---|
| R001 | 税区分が「不明」（「諸口」は除く） |
| R022 | 売上高に「対象外」（修正必須）・「非売」（要確認） |
| R028 | 給与・法定福利費に課税仕入 |
| R044 | 受取利息に課税売上 |
| R068 | 2026/10/1以降の取引に「80%控除」が残っている |
| R036 | 10万円以上の消耗品費 |
| R035 | 20万円以上の修繕費 |
| R054 | 摘要の言葉と科目が合わない |
| EX-摘要空欄 | 摘要が空欄 |
| R051 / R052 | 重複候補（同じ日 / 3日以内。1,000円未満と、摘要が違うものは比べない） |
| R055 | 同じ摘要で科目が分かれている（「当月分」「振込」などの決まり文句は除く） |

番号は所内の仕訳チェックルール集（journal-check）と同じです。
